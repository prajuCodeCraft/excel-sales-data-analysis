# 📊 Excel Sales Data Analysis

> Turning raw sales data into meaningful business insights using Microsoft Excel.

## 🚀 About the Project

This project is an **Excel-based Sales Data Analysis Minor Project** focused on exploring, cleaning, and analyzing a real-world style sales dataset.

The project uses Excel formulas, Pivot Tables, lookups, aggregation, and advanced analysis techniques to answer practical business questions.

## 🎯 What I Analyzed

- 🧹 Data cleaning and validation
- 🔎 Customer and product lookups
- 💰 Revenue analysis
- 📈 Sales performance
- 🏆 Top-performing sales representatives
- 🛍️ Product-wise revenue
- 🎯 Sales targets and achievement
- 📊 Pivot Table analysis
- 💡 Profit margin analysis
- 🔢 Ranking and Top-N analysis

## 🛠️ Excel Techniques Used

- `VLOOKUP`
- `SUMIFS`
- `COUNTIFS`
- `AVERAGEIFS`
- `SUMIF`
- `RANK.EQ`
- `LARGE`
- `INDEX`
- `MATCH`
- `MAX`
- `TEXTJOIN`
- Pivot Tables
- Data Cleaning
- Conditional Analysis
